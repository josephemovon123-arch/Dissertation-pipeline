# Volatility and Pricing Dynamics of Cryptocurrencies

Reproducibility code for the MSc dissertation *Volatility and Pricing Dynamics of Cryptocurrencies: Crypto–Equity Integration as a Standing, Non-Monotonic Exposure* (MSc Financial Technology and Innovation, Bayes Business School, City St George's, University of London, 2026).

## Overview

This repository contains the full analysis pipeline for the dissertation. Every table, figure and coefficient estimate reported in Chapter 4 and Appendix B is reproducible from the scripts and data here. The empirical work estimates HAC-robust OLS pricing regressions of Bitcoin and Ethereum daily returns on the S&P 500 and the change in the VIX, and tests whether crypto–equity integration follows a secular trend, a stress-activated switch, or a non-monotonic structure.

## How to reproduce

1. Install [R](https://www.r-project.org/) (version 4.0 or later) and the `ggplot2` package: `install.packages("ggplot2")`. The optional cross-validation against `sandwich::NeweyWest` and the Breusch–Godfrey serial-correlation test additionally require the `sandwich` and `lmtest` packages.
2. Clone or download this repository.
3. In R, set the working directory to the repository folder.
4. Source the scripts in this order, in a single R session:
   ```r
   source("dissertation_pipeline.R")   # builds D and ols_hac; runs baseline regressions
   source("part5_state_and_trend.R")   # state, trend and robustness specifications
   source("make_tables.R")             # writes tables/  (Tables 1–7, 9, 10)
   source("make_all_figures.R")        # writes figures/ (Figures 1–5)
   ```
   After step 4a, confirm `nrow(D)` returns `1638`.

## Method note

The HAC estimator uses a Bartlett kernel with automatic lag length L = ⌊4(T/100)^(2/9)⌋ = 7 and a finite-sample n/(n−k) adjustment, and is cross-validated against R's `sandwich::NeweyWest` to machine precision. Serial correlation is diagnosed with a Breusch–Godfrey test; HAC inference is therefore a demonstrated necessity rather than a precaution.

## Data source

Both panels are derived from Yahoo Finance daily closes over the full window (`price_source = "Yahoo Finance"`), with CoinGecko retained as an independent validation source over its available overlap. The two vendors' returns reconcile to a correlation above 0.999 (see Appendix B.4 of the dissertation). In `panel_a_7day.csv`, restrict to `in_sample == TRUE` to reproduce the 2,384-observation Panel A used in the dissertation; the earlier rows are warm-up only.
